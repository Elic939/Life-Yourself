# 页面实施规格

2026-09-13：用户明确要求按已给开发计划连续执行，据此沿用已展示的七页框架进入实现，不重复请求阶段许可。视觉采用清晰的浅色 Windows 原生控件，可在成品中继续调整，不声称用户逐项确认了色值。

窗口默认 1200×820，最小 900×650；左导航 180，内容留白 24，编辑面板 360。七页顺序：首页总览、今日计划、健身计划、饮食计划、游戏娱乐、总结日志、数据与设置。各页面内容可滚动，日期共用，切页保持日期。设置隐藏日期条。

| 页面 | 区块 | 编辑和操作 |
| --- | --- | --- |
| 首页总览 | 事项完成率、下一安排、事项、训练、四餐/饮水、娱乐、日志 | 勾选事项、按日期进入模块 |
| 今日计划 | 按时间、未安排时间、折叠已完成、模块安排入口 | 右侧编辑标题、日期、时间、优先级；删除撤销 |
| 健身计划 | 当日训练/休息、力量动作逐组实际表、有氧时长、历史 | 编辑训练、动作、组，计划与实际分开；完成、删除撤销 |
| 饮食计划 | 四餐计划/实际、饮水列表与总量 | 原位编辑、照计划记录、清除餐次；饮水增改删 |
| 游戏娱乐 | 计划时段、实际列表、日/周累计 | 右侧计划表单、实际区间/直接分钟表单 |
| 总结日志 | 心情、总结、收获、改进、当天足迹、历史 | 原位自动保存、删除撤销、历史跳转 |
| 数据与设置 | 路径、导出、恢复、周起点、清空 | 系统文件选择、恢复预览、明确确认 |

训练面板：力量计划组数/次数/重量与实际每组分开；有氧只要求分钟，不要求重量。删除整次训练包含子动作和组，撤销整体恢复。

恢复确认：显示导出时间、各类数量、整份替换说明；提供先导出当前数据、恢复、取消。校验失败不出现可提交恢复按钮。

共用状态：空数据有添加入口；保存中、已保存、失败重试；无效字段保留输入；删除后10秒撤销；退出失败可重试或明确放弃。无真实记录时不使用预览示例。
