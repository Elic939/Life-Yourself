# 我的生活 · 使用说明

## 打开应用

解压 `PersonalLife-win-x64.zip`，打开其中的文件夹，双击 `PersonalLife.exe`。请保留同一文件夹里的其他文件，它们是应用的一部分。不需要登录、浏览器、网址或额外安装 .NET。

此工作目录还会提供“我的生活”快捷方式，指向已经解压好的应用。

## 每天怎么用

左侧切换七个模块。顶部可选择日期、前后一天或回到今天。切换模块会保留你选择的日期。

- **首页总览**：查看今日事项、训练、三餐、饮水、娱乐和日志摘要，可勾选事项或进入模块。
- **今日计划**：添加事项，填写名称、日期、可选时间和优先级。已完成事项可展开或折叠。
- **健身计划**：先安排训练日或休息日，再添加动作。力量动作记录每组实际次数和重量，有氧记录实际分钟。可以修改或删除，整次训练删除后可撤销。
- **饮食计划**：填写四个餐次的计划和实际。“照计划记录”复制当前计划，之后可单独修改实际。饮水可以快速增加 250 ml，也可自定义。
- **游戏娱乐**：分别填写娱乐安排和实际游玩记录。实际可填分钟，或开始与结束日期时间；跨午夜的记录归到开始那天。
- **总结日志**：心情、总结、收获、待改进都可选填，文字自动保存，一天一篇。
- **数据与设置**：查看数据路径、打开数据文件夹、导出和恢复备份、调整一周起点、清空数据。

时间填写为 `HH:mm`，例如 `18:30`；日期为 `yyyy-MM-dd`。实际游戏区间填写 `yyyy-MM-dd HH:mm`，例如 `2026-09-13 23:30`。

## 保存状态

有效编辑会自动保存，通常停止输入约半秒后开始写入。底部“已保存”表示已写入本机数据文件；“保存中”表示仍在处理。

若显示未保存或保存失败，请修正字段或点击重试。切换模块和退出会等待保存；失败时保留输入。编辑面板的“放弃尚未保存的修改”只丢弃尚未成功保存的草稿，不撤回此前已经自动保存的编辑。

普通删除后 10 秒内可以点“撤销删除”。清空全部数据和整份恢复需要确认，不提供普通撤销，请先导出备份。

## 数据在哪里

正式数据保存在 Windows 当前用户的本地应用数据目录：`%LOCALAPPDATA%\PersonalLife\life.db`。以应用“数据与设置”里显示的完整路径为准。

应用文件夹与数据文件夹分开。移动或更新应用不会把记录清空。不要删除数据目录；数据并不存放在浏览器缓存中。关闭应用、重新打开以及系统正常重启后，都从同一数据文件读取。

验收和自动测试使用独立测试目录，不会自动导入测试样例到正式数据。

## 备份与恢复

1. 进入“数据与设置”，点击“导出完整备份”，选择自己容易找到的位置。
2. 备份 JSON 包含全部日期、全部模块和基础设置，而不只是当天内容。
3. 恢复时选择备份，先查看导出时间和记录数量；可以先导出当前数据，再确认替换。
4. 恢复是整份替换，不合并。取消或文件无效不会改变现有数据。恢复写入失败会回滚。
5. 不要在应用运行时直接复制或改写 SQLite 主数据文件，用“导出完整备份”取得一致备份。

若启动时数据文件损坏，应用会提示并允许选择备份恢复；原损坏文件另存保留。没有有效备份时请取消，避免覆盖原文件。

## 更新应用

先关闭应用，将新版解压到新的程序文件夹，打开新版 `PersonalLife.exe` 即可继续读取原数据。不要把新版的任何演示或测试文件复制到数据目录。V1 不使用联网自动更新。

## 适用范围

这是 Windows x64 本地桌面应用，面向当前电脑使用。没有账号、联网数据服务、手机端、自动游戏监控或营养数据库。

开发阶段已执行的检查与仍需实际机器操作的检查，请查看 `docs/acceptance.md`，不要把“进程重开测试”当成“实际重启电脑”。
